# Code of Conduct

## The short version

Be decent. Assume good faith. Critique code and ideas, never people.

## Expected behaviour

- Give feedback that is specific and actionable. "This will lose the update under concurrent
  writes, see ADR-0004" is useful; "this is wrong" is not.
- Accept feedback the same way. A review comment is about the change, not about you.
- Prefer evidence over assertion. This project has an evaluation harness precisely so that
  disagreements about the classifier can be settled with numbers.
- Respect people's time. Small PRs, clear descriptions, working reproductions.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, deliberate intimidation, publishing others'
private information, and sustained disruption of discussion.

## Enforcement

Report concerns to a.kogut01@gmail.com. Reports are handled confidentially. Maintainers may
remove comments, close issues, or block accounts for behaviour that violates this policy.
